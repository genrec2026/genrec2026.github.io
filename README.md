## Edit Content

The site is a static GitHub Pages site. Update `index.html` for workshop copy, speakers, organizers, and schedule. Update files in `assets/` for styling, scripts, and images.

## Publish on GitHub Pages

This repo includes `.github/workflows/pages.yml`, which deploys the root directory to GitHub Pages on pushes to `main`.

In GitHub, go to **Settings → Pages** and select **GitHub Actions** as the source if it is not already enabled.
